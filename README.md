# landing-zhaksylykov

* **Тема:** Стоматологическая клиника (услуги, врачи, запись)
* **Ссылка на живой сайт:** [https://daulet2305-2026.github.io/landing-zhaksylykov/](https://daulet2305-2026.github.io/landing-zhaksylykov/)

## Что реализовано:
- Семантическая верстка (header, nav, main, section, article, footer).
- Иерархия заголовков (h1 -> h2 -> h3).
- Форма обратной связи с полями Имя, Email, Сообщение (с тегами label и атрибутом required).
- Адаптивный дизайн для мобильных устройств (375px) и ПК (1280px).
- Добавлены мета-теги (viewport, description), title и favicon.
