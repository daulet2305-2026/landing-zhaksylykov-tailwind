# Лендинг: Стоматологическая клиника (Tailwind CSS)

* **Тема:** Стоматологическая клиника (услуги, врачи, запись)
* **Ссылка на живой сайт:** [https://daulet2305-2026.github.io/landing-zhaksylykov-tailwind/](https://daulet2305-2026.github.io/landing-zhaksylykov-tailwind/)

## Что реализовано:
- Семантическая верстка (header, nav, main, section, article, footer).
- Иерархия заголовков (h1 -> h2 -> h3).
- Использование **Tailwind CSS** через Play CDN для быстрой утилитарной верстки.
- Адаптивная сетка карточек с помощью Tailwind (`grid-cols-1 md:grid-cols-2 lg:grid-cols-3`).
- Интерактивное мобильное меню (бургер-навигация).
- Форма обратной связи с полями Имя, Email, Сообщение (с тегами label и атрибутом required).

## Почему этот инструмент (Tailwind CSS)
Tailwind CSS предоставляет мощные готовые утилитарные классы прямо в разметке, что позволяет очень быстро собирать интерфейсы без переключения между HTML и CSS файлами. Он удобен тем, что адаптивность настраивается интуитивно через префиксы (`sm:`, `md:`, `lg:`), избавляя от написания множества медиазапросов вручную. Однако на начальном этапе обилие классов может усложнять чтение HTML-кода. В отличие от чистого CSS, здесь не нужно придумывать названия классов, а в сравнении с Bootstrap стили выглядят более гибкими и настраиваемыми.
